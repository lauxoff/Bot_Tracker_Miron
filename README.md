# Трекер Мирона

Telegram-бот для записи кормлений, сна, прогулок и смен подгузника. В качестве хранилища используется SQLite.

## Перед запуском

Токен бота был опубликован в исходном коде. Отзовите его через [@BotFather](https://t.me/BotFather), выпустите новый и замените `BOT_TOKEN` в локальном `.env`. Не публикуйте `.env` и не вставляйте токен в исходный код.

Укажите числовые Telegram ID доверенных пользователей в `ALLOWED_USER_IDS` через запятую. Без этого бот намеренно не запускается. Укажите ID тех, кому разрешена команда `/reset_today`, в `ADMIN_USER_IDS`; эти пользователи автоматически получают доступ и к остальным функциям. Пустой список администраторов отключает сброс.

`.env.example` содержит шаблон настроек. Скопируйте его в `.env`, если локального файла ещё нет, и замените примеры настоящими значениями.

## Запуск в Docker

```sh
docker compose up --build -d
```

SQLite-база хранится в `miron_tracker.db` и монтируется в контейнер отдельно от исходного кода и секретов. Сохраняйте резервную копию этого файла.

## Запуск локально

Нужен Python 3.11 или новее:

```sh
python -m pip install -r requirements.txt
python bot.py
```

При локальном запуске база данных сохраняется по пути из `DATABASE_PATH`.

## Поведение

- Произвольное число записывается как кормление только после нажатия «Свое количество»; запрос ввода привязан к чату и пользователю и истекает через 5 минут.
- Запись кормления с единицей измерения, например `120 мл`, принимается и без предварительного меню.
- Отчёт показывает события, пересекающие полночь, но учитывает в суммах только время текущих суток.
- `/reset_today` удаляет события текущего дня, не удаляет историю прошлых дней и сохраняет текущий статус сна или прогулки. Для события сна или прогулки через полночь сохраняется часть до начала текущего дня.
